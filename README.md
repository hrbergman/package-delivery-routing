### Package Delivery Routing System
**Python, custom hash table, weighted graph** | B.S. Computer Science

A command-line delivery routing application that plans daily delivery for 40 packages under real-world constraints while keeping total mileage under 140 miles.

- Implemented a custom hash table for fast package and address lookup, and a weighted graph built from a distance table to represent the delivery network
- Routed packages across two trucks and three trips using distance-based ordering while honoring deadlines, delayed arrivals, grouped deliveries, and a mid-day address correction
- Built an interactive menu for checking any package's status at any time of day, viewing total mileage, and reviewing special-handling packages
- Documented time and space complexity throughout the code
